# GardenPay

Веб-система обліку садівничого товариства: реєстр ділянок і членів, тарифи, лічильники, нарахування, платежі, боржники та звіти в одному місці.

A web-based garden-association management system: plots and members registry, tariffs, meters, charges, payments, debtors and reports in one place.

> 🟢 **Live:** https://garden-pay-seven.vercel.app/
